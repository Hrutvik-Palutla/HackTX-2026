# Home-page illustrations

Built with the Anatomy skill (MIT, by Ryan; `kit/LICENSE-anatomy`). Each folder has a `build.mjs` that writes
`apps/web/public/illustrations/<name>.svg` (light theme, standalone). Rebuild one with `node apps/web/illustrations/<name>/build.mjs`.

`kit/figure.mjs` adds the figurines (people), the typing bubble, rotation frames and the motion CSS shared by the scenes.
